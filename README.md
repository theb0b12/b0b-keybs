# b0b-keybs

These are keyboards that I have designed (sometimes with the help of other people), including keyboards I make for commissions for other people (noted with a (C)). These are entirely my own designs, all are open source under the AGPL v3 license. I have not included just pcbs or other parts of designs that I have as commissions. Only full keyboard builds here :), but if you want they are on my github if you look around a little.

While I would like other people to not use these designs for commercial gain, I also believe in FULLY open source, unlike what most people do which is CC BY-NC 4.0 or some other creative commons license. So you do what ever you want with these, using the AGPL license.

If you are looking for the firmware for these keyboards, most are zmk, so just search zmk-config-(keyb name here).
My fork of the qmk repo has the qmk keyboards.
